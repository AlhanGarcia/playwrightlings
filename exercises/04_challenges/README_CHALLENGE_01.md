# 🏆 Milestone Challenge 1: The Login & Authentication Flow

Congratulations on completing the first 5 exercises! Now it is time to test your skills on a realistic end-to-end user scenario.

---

## 🎯 The Scenario
A user needs to log into a secure dashboard.
- If credentials are wrong, an error message is displayed.
- If valid credentials are provided, the user transitions to the Dashboard, which greets them with their email.
- The user can click 'Log Out' to return to the login screen.
